PURIXA WATER SOLUTION — WEBSITE UPGRADE v3

This package is prepared for the existing GitHub Pages repository:
https://github.com/purixawater/purixa-website
Live site: https://purixawater.github.io/purixa-website/

FILES
- index.html: full responsive website, updated business address and contact actions
- style.css: responsive styling and mobile floating-button fixes
- script.js: mobile navigation, back-to-top button and WhatsApp service-request form
- Logo.webp: original Purixa logo preserved
- domestic-ro.webp, undersink-ro.webp, commercial-plant.webp, ro-spares.webp, technician-new.webp, water-testing.webp: refreshed visual assets
- robots.txt, sitemap.xml: SEO files retained

DEPLOYMENT
1. Download and extract this ZIP.
2. Open the existing purixa-website GitHub repository.
3. Upload the contents of this folder into the repository root (not the enclosing folder).
4. Replace matching files when GitHub asks, but keep the repository settings and branch.
5. Commit changes. Wait for GitHub Pages to publish, then test the live site on mobile.

IMPORTANT
- The website request form prepares a message and opens WhatsApp; it does not store customer data on the website.
- The Google Maps button opens a search for the supplied address. Please verify the exact pin in Google Maps before advertising the location.
- Product/service visuals are illustrative and should not be represented as photographs of a specific stocked model or a real completed installation. Replace them with actual photos whenever available.
- This ZIP does not publish itself; the GitHub repository must be updated to change the live website.
